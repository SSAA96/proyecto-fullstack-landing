# Flowly — Landing Page
 
Landing page de una sola página para **Flowly**, plataforma ficticia para organizar tareas, automatizar trabajo repetitivo y ver el progreso de equipo en tiempo real. Proyecto del diplomado fullstack.
 
## Integrantes
 
- James Wilson Marambio
- Sebastián Sandoval Álvarez
 
## Tecnologías
 
- HTML5 + CSS3
- [Bootstrap 5.3](https://getbootstrap.com/) (CDN)
- [Bootstrap Icons](https://icons.getbootstrap.com/) (CDN)
- JavaScript vanilla
- Fuentes: Inter y Poppins (Google Fonts)
 
## Demo

- Sitio desplegado: https://ssaa96.github.io/proyecto-fullstack-landing/

## Estructura
 
```
├── index.html      # Página principal
├── css/
│   └── custom.css  # Estilos propios
├── js/
│   └── main.js     # Interactividad (modo oscuro, etc.)
└── img/            # Logo y avatares
```
 
## Secciones
 
- Header / navbar con toggle de modo oscuro
- Hero
- Features
- Testimonios
- Precios
- Contacto / Footer
 
## Uso
 
Abrir `index.html` en el navegador. No requiere build ni instalación de dependencias.
